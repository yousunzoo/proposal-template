# 과거 이관 검토 메모

작성일: 2026-08-20
상태: 폐기된 방향

이 문서는 과거에 제안서 기능을 외부 관리 시스템으로 이관하는 방안을 검토했던 흔적이다.
2026-09-03 기준 제품 방향은 변경되었다.

현재 기준:

- `proposal-template`은 포트폴리오 기반 제안서 생성을 위한 독립 제품 프로토타입으로 유지한다.
- 민감정보가 포함될 수 있는 실명, 고객사명, 실제 서비스명, 운영 지표, URL은 기본 데이터와 샘플에서 제거한다.
- 현재 제품화 로드맵은 [`docs/productization-roadmap.md`](productization-roadmap.md)를 기준으로 한다.
